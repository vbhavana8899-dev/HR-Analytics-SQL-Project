# HR Analytics and Employee Attrition Analysis

## Project Overview
This project uses MySQL to analyze employee attrition and explore workforce trends using HR analytics data.

## Dataset
- Dataset: IBM HR Analytics Employee Attrition and Performance
- Total records: 1,470 employees
- Database: MySQL

## Objectives
- Calculate the overall employee attrition rate.
- Analyze attrition across departments.
- Investigate attrition by overtime status.
- Examine the relationship between job satisfaction and attrition.
- Compare attrition across salary groups.

## SQL Concepts Used
- SELECT, WHERE, ORDER BY
- Aggregate functions: COUNT(), SUM()
- GROUP BY
- CASE statements
- ROUND()
- Percentage calculations

## Key Findings
- Total employees analyzed: 1,470
- Employees who left: 237
- Overall attrition rate: 16.12%
- Research & Development had the highest number of departures (133).

## Tools
- MySQL
- SQL
- GitHub

## How to Run
1. Create the database and employees table.
2. Import the dataset into MySQL.
3. Run the SQL scripts in order.
